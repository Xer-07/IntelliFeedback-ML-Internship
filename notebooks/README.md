# Jupyter Notebooks Roadmap

This folder organizes the exploratory and experimental notebooks across the 5 internship sprints:

| Sprint | Notebook Name | Description |
| :--- | :--- | :--- |
| **Week 2** | `01_eda_and_data_cleaning.ipynb` | Text distribution, class imbalance, token profiling, and text cleaning pipeline. |
| **Week 3** | `02_feature_extraction_and_baselines.ipynb` | TF-IDF n-grams vectorization, Naive Bayes, Logistic Regression, LinearSVC benchmarks. |
| **Week 4** | `03_hyperparameter_tuning_and_deep_learning.ipynb` | GridSearchCV optimization, DistilBERT fine-tuning, error analysis, and metric evaluation. |
| **Week 5** | `04_model_evaluation_and_inference.ipynb` | Confusion matrices, ROC-AUC calibration, model export to `.joblib`, and test inference. |
